# Rendering checklist

For each output:

1. Confirm the `output_id`, `sap_id`, and `shell_id` against the spine and shell.
2. Verify each table row, column, label, denominator, and statistic against the approved shell and ARD.
3. If any display choice is unspecified, ask; do not invent a rule or recalculate an ARD.
4. Save the table under `outputs/<output_id>.*` and retain the source mapping in a trace note.
5. Have a qualified reviewer QC the rendered output before any GxP use.
